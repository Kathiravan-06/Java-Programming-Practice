
# Java Programming Practice

This repository contains 5 Java programming problems and their solutions, focusing on Object-Oriented Programming concepts and problem-solving techniques. Java programming problems and solutions covering inheritance, exception handling, validation, and OOP concepts.

## Questions Covered

| No. | Problem Name | Concepts Used |
|---|---|---|
| 1 | Temporary Staff Salary Calculation | Multilevel Inheritance |
| 2 | Date Parse Exception Handling | Exception Handling |
| 3 | Vehicle Speed Calculation | Inheritance, Super Keyword |
| 4 | Password Validation | Encapsulation, Exception Handling |
| 5 | Doctor Details | Classes and Objects |

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Exception Handling
- Java Collections and Utility Classes

## How to Run

1. Clone the repository.
2. Open the required question folder.
3. Compile the Java program.
4. Execute the program.

Example:

    javac Main.java
    java Main

For Question 4:

    javac PasswordMain.java
    java PasswordMain
